# FROGGER - arcade remake

Browser remake of the 1981 arcade game. Hand-drawn sprites and synthesized sound, no ROM data.

Play: https://bamtec70.github.io/frogger-game/

## Controls

- Arrow keys or WASD: hop
- 5: coin
- 1, Enter or Space: start
- M: sound on or off (session only)
- On a phone: direction pad under the left thumb, coin and start under the right thumb
